🚀 Task Reminder - Smart & Sleek

Task Reminder es una aplicación de gestión de tareas para Android, diseñada para ser ligera, visualmente atractiva y, sobre todo, efectiva. A diferencia de otras apps de notas, esta aplicación utiliza un sistema de recordatorios inteligentes que te mantiene motivado mediante notificaciones aleatorias.

✨ Características Principales

🎨 Personalización Total: Cambia el color del tema de la app y disfruta de un Modo Oscuro real y persistente.

🔔 Notificaciones Inteligentes: Sistema de alertas automáticas que selecciona tareas pendientes al azar y te las recuerda con frases motivacionales.

⚡ Acciones Rápidas: Marca tareas como completadas o pospón recordatorios (Snooze 15 min) directamente desde la notificación, sin abrir la app.

🔴 Gestión por Prioridades: Clasifica tus tareas en niveles (Baja 🟢, Media 🟡, Alta 🔴) con códigos de colores visuales.
edit & Swipe: Edición mediante pulsación larga y borrado rápido deslizando hacia los lados.

💾 Persistencia de Datos: Tus tareas se guardan localmente mediante GSON, incluso si reinicias el dispositivo (BootReceiver incluido).

🔒 Privacidad: Sin registros ni subida de datos a la nube. Todo se queda en tu teléfono.

🛠️ Tecnologías Usadas
Lenguaje: Java
UI: Material Design 3 (Material Components)
Almacenamiento: SharedPreferences + GSON
Notificaciones: Notification Manager + Alarm Manager (Exact Alarms)
Arquitectura: Broadcast Receivers para persistencia tras reinicio y manejo de alarmas en segundo plano.

📝 Cómo usarla
Añadir: Pulsa el botón + blanco para crear una tarea y elige su prioridad.
Completar: Pulsa una vez sobre la tarea para marcarla como hecha.
Editar: Mantén pulsada una tarea para corregir el texto o cambiar la prioridad.
Borrar: Desliza la tarea hacia la izquierda o derecha.
Ajustes: Usa el icono de engranaje para cambiar el color de la interfaz o activar el modo noche.
